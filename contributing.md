# Contribution Guidelines

Thanks for helping make this list better! Please keep the following in mind.

## What belongs here

This list targets **store owners and operators** running ecommerce and dropshipping businesses. An entry should be something a store owner can practically **learn from, use, or buy** — a platform, supplier, tool, service, or high-quality piece of knowledge.

Forward-looking agent-to-commerce protocols and GEO research belong in the sibling list, [Awesome Agentic Commerce](https://github.com/MentionNetwork/awesome-agentic-commerce).

## Rules for a good entry

- One resource per pull request when possible — it keeps review fast.
- Use the format: `[Name](https://example.com) - Short, neutral description.`
- Descriptions must be **neutral and factual**. No marketing hype, no "best ever", no exclamation marks.
- Descriptions start with a capital letter and end with a period.
- Add the entry to the **most relevant existing section**, alphabetically or by relevance where the section is ranked.
- The resource must be **actively maintained** and genuinely useful — no dead links, no thin affiliate landing pages.
- No duplicates. Search the list first.

## Adding a new section

If a group of related resources doesn't fit any section, propose a new one — add it to the Contents table of contents and keep the ordering logical.

## Data-backed entries

The **High-Demand Product Categories** section uses real search-volume data. If you add or update figures, cite the source and market (e.g. "US, Google Ads") so numbers stay comparable.

## Pull request checklist

- [ ] The resource fits the scope (operator-focused).
- [ ] The link works and points to the canonical URL.
- [ ] The description is neutral, correct, and follows the format.
- [ ] No duplicate entry already exists.
- [ ] Placed in the correct section.
